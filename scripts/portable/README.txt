赛博大师·八字与紫微斗数排盘计算器 — Windows 便携测试候选

1. 将整个 ZIP 解压到你有写权限的本地文件夹（建议短路径），不要在 ZIP 内直接打开。
2. 双击 Start.cmd；程序会使用包内 Node.js 并打开默认浏览器。
3. 如果浏览器没有打开，复制窗口中 http://127.0.0.1:端口 地址手动打开。
4. 保持命令窗口打开，结束时按 Ctrl+C；仅关闭网页不会停止程序。

无需安装 Node.js、npm 或依赖；不需要管理员权限，运行时可断网。
x64 和 ARM64 是不同的运行时包，应选择与 Windows 系统架构一致的版本。

案例在首次使用时写入本文件夹的 data 目录。该目录包含个人资料，务必自行备份。
升级时请先退出程序，解压新版本到新文件夹，再复制旧 data 目录；不要覆盖唯一备份。
卸载时删除程序文件夹即可；删除 data 也会删除案例。下载的导出文件由浏览器保存。
程序只监听 127.0.0.1，不主动上传案例；复制给 AI 或分享导出文件会将内容交给接收方。
重新分发时使用维护者新构建的原始包，不要压缩你使用过的文件夹、data 或浏览器下载。

本包是测试候选。构建成功、布局检查或自动测试不代表 Windows 实机与浏览器验收通过。
PORTABLE-MANIFEST.json 记录版本、运行时与文件校验值，不提供自动更新或安装功能。
遇到 Windows 安全提示请核对来源与校验值，并交由维护者排查，不要关闭系统安全防护。
